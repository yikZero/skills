# Humanize (English)

Strip AI flavor from English drafts. Rewrite and review modes only, no ghostwriting: a 27-pattern table (words, structures, style, voice, content), honesty rules against fabricated anecdotes and numbers, anti-overcorrection guidance, and a pre-delivery checklist with scoring. Chinese counterpart: `humanize-zh`.

## Install

```bash
npx yskill --skill humanize-en
```
