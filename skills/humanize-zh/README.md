# Humanize (中文改稿)

Strip AI flavor from Chinese drafts. Rewrite and review modes only, no ghostwriting: a 30-pattern table across six layers (词汇、句式、结构、标点、语气、内容), honesty rules against fabricated anecdotes and numbers, anti-overcorrection guidance, and a pre-delivery checklist with scoring. English counterpart: `humanize-en`.

## Install

```bash
npx yskill --skill humanize-zh
```
